# ChessVision AI

Шахматный AI-помощник для Android: настоящий **Stockfish** прямо в телефоне (офлайн), распознавание позиции со скриншота, разбор партий, задачи, тренировки и игра против движка.

## Возможности

| Режим | Что делает |
|---|---|
| **Analysis** | Анализ позиции Stockfish в реальном времени: до 5 линий (MultiPV), оценка в сантипешках, «мат в N», глубина, скорость. Стрелки лучших ходов разными цветами, подсветка клеток, шкала оценки, просмотр продолжения любой линии по ходам, ввод FEN/PGN, редактор позиции. |
| **Screenshot** | Распознавание позиции с картинки: поиск доски, 64 клетки, тип и цвет фигур, ориентация доски, сборка FEN, проверка корректности. Ручное исправление с запоминанием, калибровка под стиль фигур по начальной позиции. |
| **Training** | «Найди ход Stockfish»: позиции из твоих ошибок (после разбора партий) или из задач. Движок оценивает твой ход и объясняет потерю. |
| **Puzzles** | Тактические задачи, каждая проверена Stockfish (решение — единственный сильный ход). Рейтинг по Эло, подсказки, показ решения, генерация новых задач прямо на телефоне. |
| **Game Review** | Разбор партий: точность игроков, классификация ходов (лучший / отлично / хорошо / неточность / ошибка / зевок / упущенная победа), график оценки, лучшие ходы. Импорт PGN (вставка или файл). Ошибки уходят в тренировку. |
| **Practice** | Игра против Stockfish: сила по Elo (1320–3190, UCI_Elo) или по уровню 0–20, выбор цвета, подсказка, отмена хода, сдача. Партии сохраняются и разбираются. |

Хранение партий, ошибок, статистики задач и выученных образцов фигур — Room (SQLite). Весь анализ асинхронный (Kotlin Coroutines), поиск можно прервать в любой момент.

> Подсказки движка — для разбора, тренировок и задач. Не используй их во время живых партий на шахматных сайтах: это нарушает правила fair play. Приложение не запускается поверх других приложений и не захватывает экран само — только картинки, которые ты выбрал.

## Установка APK

1. Открой страницу **Releases** этого репозитория и скачай последний `ChessVisionAI-<номер>-arm64.apk` (для почти всех телефонов последних лет, включая Huawei P60 Pro). `armv7` — только для старых 32-битных устройств.
2. Открой файл на телефоне. Если Android спросит — разреши установку из этого источника (Настройки → Безопасность → «Установка неизвестных приложений» для браузера или файлового менеджера). На Huawei/EMUI: Настройки → Безопасность → Дополнительные настройки → Установка приложений из внешних источников.
3. Запусти ChessVision AI. На главном экране должно появиться «Stockfish 19» с зелёной точкой — движок работает.

Обновление: ставь новый APK поверх старого, данные сохранятся (все сборки подписаны одним ключом).

## Сборка в Android Studio

Требования: Android Studio (Ladybug или новее), JDK 17 (встроен в Studio), интернет при первой сборке.

1. `File → New → Project from Version Control` → URL этого репозитория (или скачай ZIP и открой папку).
2. Дождись синхронизации Gradle (скачаются Android Gradle Plugin 8.7, Kotlin 2.1, Compose, Room).
3. Выбери конфигурацию `app` и нажми **Run** (телефон по USB с включённой отладкой) или `Build → Build APK(s)`.

При первой сборке Gradle-задача `downloadStockfish` сама скачает официальные Android-сборки Stockfish со страницы релизов [official-stockfish/Stockfish](https://github.com/official-stockfish/Stockfish/releases) и положит их в `app/src/main/jniLibs/<abi>/libstockfish.so`. Конкретный релиз можно задать: `./gradlew assembleRelease -PstockfishTag=sf_19`.

Из командной строки:

```bash
./gradlew assembleRelease          # APK: app/build/outputs/apk/release/
./gradlew :core:selfTest -PstockfishPath=/путь/к/stockfish   # тесты ядра и движка
./gradlew :core:generatePuzzles -PstockfishPath=/путь/к/stockfish -PpuzzleCount=200 -PpuzzleMinutes=20
```

## Автосборка (GitHub Actions)

Каждый push запускает `.github/workflows/build.yml`:

1. скачивает Linux-Stockfish и прогоняет тесты ядра: правила шахмат (perft), FEN/SAN/PGN, распознавание доски на синтетических скриншотах, **интеграцию с настоящим Stockfish** (мат, MultiPV, прерывание поиска, ограничение силы, разбор партии);
2. собирает release-APK;
3. если банка задач ещё нет — генерирует и проверяет задачи Stockfish и коммитит `app/src/main/assets/puzzles.json`;
4. публикует APK в Releases.

## Архитектура

```
core/  — чистый Kotlin (JVM), тестируется без Android
  chess/   Position (полные правила), Fen, San, Pgn, Game, PositionValidator
  engine/  UciEngine (процесс + UCI, MultiPV, мат, сила), GameReviewer, MoveClassifier, PuzzleGenerator
  vision/  BoardDetector (поиск доски + выравнивание по линиям сетки), CellAnalyzer (силуэты),
           PieceClassifier (ближайший сосед), BoardRecognizer (цвет, ориентация, согласованность), ReferenceBuilder
  svg/     мини-парсер SVG для наборов фигур
app/   — Android (Kotlin, Jetpack Compose, Room, Navigation)
  engine/  EngineManager (запуск libstockfish.so), AnalysisController (живой анализ)
  vision/  RecognitionService (загрузка изображения, обучение на исправлениях)
  ui/      доска (Canvas: стрелки, подсветка, drag&drop, анимация), экраны всех режимов
```

**Как устроено распознавание.** Доска ищется по «шахматному» признаку: цвета в углах 64 клеток (там почти никогда нет фигур) должны делиться на два чётко различимых чередующихся класса. Поиск идёт от грубого к точному, затем рамка уточняется по градиенту на линиях сетки с точностью до пикселя. В каждой клетке выделяется силуэт фигуры (отличие от фона + заливка контура), из него считаются признаки формы, и тип фигуры определяется ближайшим соседом среди эталонов. Эталоны рендерятся из встроенных наборов фигур на типичных цветах досок, плюс туда добавляются образцы, которые выучены на твоих исправлениях и калибровке. Цвет фигуры определяется по яркости внутренней области (2-means по всей доске), ориентация — по расположению пешек и королей.

Точность на тестах (синтетические скриншоты: разные темы досок, подписи координат, подсветка последнего хода): доска найдена в 100% случаев, наличие и цвет фигур — 100%, тип фигуры — 99–100% для стилей Cburnett/Merida/Alpha. Для непохожих 3D-стилей — около 94%, после калибровки — 100%.
